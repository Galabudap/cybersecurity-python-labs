## Завдання 1

```powershell
python -m labs.lab02.main demo
```

Демонстрація успішного й невдалого входу, перевірки email,
прав адміністратора, таймауту, виходу та журналу аудиту.

Паролі перевіряються через PBKDF2-HMAC-SHA256 із випадковою
сіллю та hmac.compare_digest. Час сеансів і аудиту зберігається в UTC.
Таймаут сеансу — 900 секунд; демонстрація імітує його завершення.

## Завдання 2

```powershell
python -m labs.lab02.main analyze --targets labs/lab02/data/data_v05/targets.json --timeout 1 --out-csv labs/lab02/scan_results.csv --verbose
```

Параметри:

- --targets — обов'язковий шлях до JSON зі списком об'єктів host і port.
- --timeout — додатний час очікування TCP-підключення в секундах;
  типове значення — 1.
- --out-csv — обов'язковий шлях до таблиці результатів.
- --verbose — увімкнення докладних повідомлень DEBUG.

Програма виконує реальні TCP-підключення.
Пошук адреси через DNS та перевірка кількох адрес одного імені
можуть збільшувати загальний час перевірки.

## Статуси та обробка помилок

- ONLINE — TCP-з'єднання встановлено.
- OFFLINE — підключення відхилено.
- TIMEOUT — вичерпано час очікування.
- DNS_ERROR — не вдалося визначити адресу за ім'ям.
- INVALID — неправильна адреса, порт або структура запису.
- ERROR — інша помилка мережевого підключення.

Некоректні записи не припиняють перевірку решти списку.
Помилки читання JSON і записування результатів обробляються
з повідомленням та кодом завершення 1.
Некоректні аргументи командного рядка відхиляє argparse.

Результат навчального запуску:
11 записів, TIMEOUT — 6, DNS_ERROR — 2, INVALID — 3.
Мережеві результати можуть відрізнятися при повторному запуску.
